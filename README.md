## ⚡ 30 秒上手

1. **下载**：点上面的蓝色按钮 → 页面底部 **Assets** → `TimestampRecorder_vX.Y.Z.apk` → 手机上安装（首次需允许「安装未知来源应用」）。
2. **建事件**：打开 App → 点底部 tab 栏正中间的圆形「＋」→ 填名字（比如「喝水」）→ 保存。
3. **记一条**：点那张卡片**最右边**的彩色按钮，搞定。

就这三步。之后想更快，就把[小组件](#tutorial)放桌面 —— **不用打开 App，点一下就记**。

## 🎯 它解决什么

| 你大概遇到过 | 这里怎么解决 |
|:---|:---|
| 「这会开了多久了？」「药是几点吃的？」—— 当时没记，事后想不起来 | **点一下**就写入当前时刻，精度到毫秒 |
| 想记一下时间，结果要：打开 App → 选分类 → 填表 → 保存 | 卡片上一个按钮；**桌面小组件点一下**；甚至不用解锁进 App |
| 记的是作息、吃药、喂奶这类私事，不想交给云端 | **0 权限、不联网、无账号**，数据只在本机 |
| 记了半天，看不出任何规律 | 时间线按事件染色串起来 + 统计页柱状图与 7 / 14 / 30 天趋势 |

> 它适合「要记下**确切时刻**」的场景，不适合写长日记。
> 多件事并行、需要精确到分秒、事后还要能查 —— 这才是它的主场。

## 💎 为什么不一样

真·人无我有的地方，只有这几条：

| | **时间戳记录器** | 常见记录 / 习惯类 App |
|:---|:---|:---|
| **权限** | **0 个** —— 连 `INTERNET` 都没申请，物理上无法上传 | 存储 / 网络 / 通知 / 自启动…… |
| **记录成本** | **1 次点击**写入，桌面小组件可在不打开 App 的情况下完成 | 打开 → 选分类 → 填表 → 保存 |
| **数据在哪** | 只在本机私有目录，无账号、无云、无后台 | 绑云端账号，服务一停就没了 |
| **商业化** | 无广告 / 无订阅 / 无埋点 / 无第三方 SDK | 广告 + 订阅墙 + 数据统计 |
| **换机重装** | 离线 JSON 导出与**覆盖恢复**，不用联网 | 依赖云同步 |
| **精度与导出** | 毫秒时间戳 + Unix 秒，点一下复制；CSV 带 BOM，Excel 双击不乱码 | 多半只到「分钟」，甚至只存日期 |
| **小组件** | 3 种；其中**单事件**支持 1×1 ~ 4×4 拉伸自动换版式，另两种为固定版式 | 通常只有一种固定尺寸 |
| **玻璃质感** | 全 App **实时液态玻璃**（折射 + 色散 + GPU 高斯）；页面内容一律同窗口自绘，唯一浮窗是「⋮」玻璃菜单（不吃焦点、不夺状态栏配色） | 截图假装糊 / 系统级模糊必建浮窗、夺状态栏 |
| **升级** | 全版本同一签名，**直接覆盖安装，数据一条不丢** | — |

<details>
<summary><b>还有一条偏技术的：真·实时玻璃模糊，不是「截图假装糊」</b></summary>

**全 App 统一的「液态玻璃」**（v4.0.0 起）：顶部额头、底部胶囊岛、tab 中间的加号圆钮、
二级页面顶栏，全部是**物理折射 + 色散 + GPU 高斯**的实时液态玻璃
（源自 MIT 协议的 [AndroidLiquidGlassView](https://github.com/QmDeve/AndroidLiquidGlassView)，源码集成）。
每帧把页面内容录进 RenderNode、经 AGSL 着色器实时折射 —— **同窗口捕获、不建任何浮窗**，
状态栏配色永不被夺（AOSP 实验铁证：任何浮窗都会把状态栏图标打成白色且无法点亮）。

- **为什么放弃系统「高级材质」**：系统级模糊只能模糊「窗口背后」，必须建**整屏**浮窗 → 必夺状态栏黑化
  （v3.2.x 攻坚、三轮实验锁死的互斥）。液态玻璃自绘路线两全：黑化与质感兼得，还多出折射色散。
- API < 33 的设备自动退回普通玻璃形态（v4.5.0 起补上底色与下沿分隔线 —— 此前低版本顶栏是
  **完全没有背景**的，滚动时内容会和标题字叠在一起）。
- 全 App **唯一保留的浮窗**是「⋮」/ 长按呼出的**玻璃菜单**：它以「不吃焦点」的方式弹出，
  不改系统栏外观，只负责把玻璃卡片压在内容之上 —— 这也让「点空白处收起菜单」成为可能。
  旧的整屏浮窗架构与 BlurView 依赖已全部移除。

</details>

## 🔒 隐私

- **不申请任何权限** —— manifest 里没有 `INTERNET`，也没有存储、定位、通知。
- 数据 100% 存在应用私有目录（SharedPreferences）：不上传、不联网、无后台唤醒。
- 「关于」页的 GitHub 按钮交给**系统浏览器**打开，App 自身依旧不联网。
- 卸载即彻底清除；换机前用「设置 → 数据备份」导一份 JSON 即可。

## 📖 使用教程

> App 内也有**离线教程页**：右上角「⋮」→ 使用教程（不依赖 GitHub，随时可查）。

### 界面就四个页面

| 页面 | 怎么进 | 有什么 |
|:---|:---|:---|
| **主页** | 点桌面图标 | 事件卡片列表、底部 tab 栏正中的「＋」、右上角「⋮」、底部「事件 / 时间线」双 Tab |
| **事件详情** | 点卡片**中间区域** | 大记录按钮、撤销上一条、该事件全部记录 |
| **统计** | 右上角「⋮」→ 统计 | 概览、各事件柱状图、近 7 / 14 / 30 天趋势 |
| **设置** | 右上角「⋮」→ 设置 | 排序、小组件、备份、关于 |

### 1️⃣ 新建事件

点底部 tab 栏正中间的圆形「＋」→ 填**名称**（留空会红字提示）→ 选个**颜色**（23 色 + 第 1 格「＋」可自定义，默认随机）→ 保存。

> 自定义取色器里：拖色相条与「饱和度×明度」方块选色，也可以**直接键入颜色编码**（`#RRGGBB` / `#RGB`，`#` 可省略，`#AARRGGBB` 忽略前两位透明度）。明度是**完整 0~100%**，能选到纯白与高亮浅色。

> 颜色会用在卡片圆点、快捷按钮、统计柱状图、时间线节点和桌面小组件上，挑个一眼能认出来的。

### 2️⃣ 记录一条

三个入口，效果完全一样（都是毫秒精度）：

| 入口 | 点哪里 |
|:---|:---|
| **主页快捷按钮**（最快） | 卡片**最右侧**的彩色胶囊按钮（「＋」+ 当前条数） |
| **详情页大按钮** | 进详情页 → 点顶部那块填满事件色的「记录此刻」 |
| **桌面小组件** | 桌面点组件本体，**不用打开 App** |

### 3️⃣ 事件卡片上有四个可点区（外加长按），别按错

| 位置 | 点了会怎样 |
|:---|:---|
| 最左「≡」手柄 | **按住拖动排序**（仅「手动排序」模式下显示） |
| 中间（圆点 + 名字 + 信息） | 打开**详情页** |
| 竖排「⋮」 | 弹出**玻璃菜单**：编辑事件 / 删除事件 |
| 卡片上**长按**（任意位置） | 与「⋮」**同一个菜单**：编辑事件 / 删除事件 |
| 最右彩色胶囊 | **直接记一条** |

> 玻璃菜单的三条收起方式都做了同一套 190ms 反向动画：**再次点「⋮」**、**点空白处**、**按返回键**。

> ⚠️ 删事件会连同它名下**所有记录**一起删，会先弹确认。

<details>
<summary><b>拖拽排序的细节（最容易按错的一步）</b></summary>

- **前提**：设置 → 事件排序 →「**手动排序**」（默认）。选了「按最近记录」，左侧手柄会**直接消失**。
- **手指必须按在**卡片最左边那个「≡」上。按住**瞬间**就能拖，**不用长按等待**。
- 按在卡片其它位置不会触发拖动 —— 那些地方是「打开详情页」。
- 列表很长时，拖到屏幕上/下边缘停一下会自动滚动。
- 手动顺序只存本机，没有「撤销排序」：大改之前建议在设置里先导一份备份。

</details>

### 4️⃣ 详情页：管理记录

- **记一条**：点顶部「记录此刻」大按钮。
- **撤销手滑**：点下方「撤销上一条」，删掉最新那条。
- **复制时间**：点某一行任意位置 → 复制到剪贴板（`2026-09-14 09:41:53  (Unix 秒: 1757...)`）。
- **删除一条**：长按该行 → 确认。
- **批量删除**：点标题栏复选框图标 → 底部升起 `全选 / 已选 N 项 / 删除(N) / 取消` → 点行即打勾 → 删除。
- 右上角「⋮」：编辑事件 / 导出记录（CSV）/ 查看统计 / 跳到时间线 / 清空记录 / 删除事件 —— 同为自绘玻璃菜单，删除类破坏性动作会用红色标出。

### 5️⃣ 桌面小组件

**添加**：设置 → 桌面小组件 → 先授予「创建快捷方式」权限 → 点「一键添加到桌面」。桌面不支持时，搜索「**你的手机品牌 + 添加安卓原生小组件**」找到「时间戳记录」拖到桌面即可（小米 HyperOS 4 实测：长按桌面空白处 →「小部件」→「全部应用」→ 拉到底点开「安卓小部件」）。

| 类型 | 说明 |
|:---|:---|
| **全部事件** | 列出所有事件，点哪行记哪个（最多 6 行） |
| **单事件** | 添加时绑定一个事件，**1×1 ~ 4×4 可拉伸**，版式随格子变 |
| **自定义** | 添加时自选事件、标题与背景色，一行一个事件 |

- **拉伸**：长按组件 → 拖角或边 → 松手即时换版式，不用删了重加。
- **重新绑定**：长按组件 →「重新配置 / 编辑」。
- **圆角**：设置里统一调（8 / 16 / 24 / 32dp），改完桌面立刻刷新。
- 组件显示「已删除」= 它绑的事件被删了，长按重新配置即可。

<details>
<summary><b>「一键添加到桌面」没反应？</b></summary>

「一键添加」走的是 Android 官方 `requestPinAppWidget` —— 它只是**向桌面发起请求**，
弹不弹确认框、能不能加上，完全由桌面（启动器）实现。部分品牌没有实现该接口，
点了没反应**不是本 App 的 bug**。

- 先在设置里授予「**创建快捷方式**」权限（App 内有引导按钮），返回再点「一键添加」；
- 仍无反应就手动添加：搜索「**你的手机品牌 + 添加安卓原生小组件**」，找到「时间戳记录」拖到桌面
  （单事件 / 自定义拖上后需绑定事件）；
- 参考（小米 HyperOS 4 实测路径）：长按桌面空白处 →「小部件」→「全部应用」→ 拉到底点开「安卓小部件」；
- Android 15+ 若失效，重新打开 App 再试。

</details>

### 6️⃣ 时间线

底部切到「时间线」Tab：所有记录按月份倒序串成一条线，**每个事件用自己的颜色染色**，
条与条之间渐变过渡，整条线从屏幕顶端一直连到底部。点任意一行可跳到该事件的详情页。

### 7️⃣ 设置

| 分组 | 选项 |
|:---|:---|
| **事件排序** | 手动排序（显示「≡」手柄）/ 按最近记录 |
| **桌面小组件** | 圆角四档 + 三个「一键添加到桌面」按钮 |
| **数据备份** | 导出 / 覆盖恢复（走系统文件选择器，**不需要存储权限**） |
| **使用教程 / 关于** | 离线教程页入口、版本号、GitHub 源码、MiSans 字体出处 |

> **恢复是覆盖，不是合并，且不可撤销** —— 会先弹框告诉你将被覆盖的数据量（N 个事件 / M 条记录）。

### 8️⃣ 统计

概览（事件数 / 记录总数 / 记录最多的事件）+ 各事件柱状图 + 近 7 / 14 / 30 天趋势（可切换）；区间事件额外汇总总时长 / 平均 / 最长一次。
从某个事件详情页进来时，顶部显示「当前：事件名」，可一键切回全局视图。

## 🧠 实现取舍（给想看代码的人）

| 项 | 值 |
|:---|:---|
| 语言 / 构建 | Kotlin 1.9.22 · Gradle 8.2 + AGP 8.2.2 · JDK 17 |
| UI | Material Components 1.11（M3）+ ViewBinding + RecyclerView + ViewPager2（主页跟手切页） |
| 图表 / 时间线 | **自绘 Canvas**，零第三方依赖 |
| 小组件 | AppWidget + RemoteViews（固定行渲染，不依赖 RemoteViewsService；按 `AppWidgetOptions` 实时分档） |
| 数据层 | SharedPreferences + `org.json`，写操作全 `@Synchronized`，零数据库 |
| 字体 | MiSans（裁 GB2312 子集后嵌入 assets） |
| 设计 token | 圆角 / 间距 / 玻璃参数（模糊·折射·浓度）/ 大屏宽度上限全部集中在 `res/values/dimens.xml`，深色与 `sw600dp` 各一套覆盖 |
| 菜单 | 自绘玻璃卡片 `GlassMenu`（独立窗口、不吃焦点），**不用**系统 `PopupMenu` / 溢出菜单 |
| SDK | compileSdk / targetSdk 34 · minSdk 24 |

几个值得一提的坑与决定：

- **玻璃统一为液态玻璃（自绘路线）**：系统级模糊必须建浮窗（而浮窗必夺状态栏黑化，实验锁死）；
  液态玻璃在布局内用 RenderNode + AGSL 自绘折射，两全。旧「独立窗口 + 系统模糊」架构整块移除。
- **整屏浮窗架构已删除**：三重实验证明「占满屏幕的浮窗」必夺状态栏 appearance 且无法点亮 ——
  这条路的上限就是「白图标」，已封闭并清理代码。菜单那种**小尺寸、不吃焦点**的浮窗不受此限。
- **玻璃着色的色彩空间**：AGSL 混色走 **sRGB**，曾按线性空间给深色 tint →「浓度越高反而越亮」；
  现在颜色一律以 sRGB 十六进制声明、换算收敛在 `Glass.kt` 一处，观感可回归、不靠试。
- **菜单开合动画按「时间反演」做**：展开 `Decelerate` / 收起 `Accelerate`、同时长同 pivot；
  卡片底必须挂在根视图上（挂窗口背景则不参与缩放，收起会只剩文字在缩、卡片「啪」地消失）。
- **模糊跟随系统开关**：主动读 `Settings.Secure.background_blur_enable`，用户关掉高级材质时不做模糊 —— 尊重省电选择。
- **不跟随「材质风格」**：实测差异不在系统合成器的模糊层（SF 输出逐字节相同），是 MIUI 内部接口，第三方拿不到，硬跟只会更假。
- **拖拽排序直接复用存储数组次序**：没有 `order` 字段，也就不需要数据迁移。

单人开发自用，先说清楚边界，免得你踩到没验证过的坑：

| 项 | 情况 |
|:---|:---|

| **已验证** | 新建 / 快捷记录 / 拖拽排序 / 详情页与批量管理 / 统计 / 三种小组件（单事件含 1×1~4×4 拉伸；单事件与自定义含重绑）/ 备份导出与恢复 / 覆盖安装升级 / 玻璃菜单三条关闭路径（再点锚点 · 点空白 · 返回键）/ 取色器自定义颜色 |
| **未验证** | 其他品牌与 ROM、平板与折叠屏、Android 12 以下、超大字体与横屏 |
| **已知限制** | ① 小米「一键添加」需先在设置里授予「桌面快捷方式」权限（App 内有引导按钮，见[第 5 节](#tutorial)）；realme UI 桌面未实现该通道，需手动添加 ② 液态玻璃完整效果需 **Android 13+**（AGSL 着色器）；更低版本自动退回**带底色**的普通玻璃形态（v4.5.0 前该形态没有背景） ③ 「加号位置」设置项已随 4.0.0 移除（加号固定于 tab 栏正中间） ④ 自定义取色可选到**纯白 / 高亮浅色**；这类底色上的文字与图标会被 App 自动转成**近黑色**以保证可读 —— 因此同一列表里可能**黑白字混排**，是「支持完整亮度范围」的**有意取舍**，不是 bug |
