隐私政策

时间戳记录器（Timestamp Recorder）· 更新日期：2026-09-16

本隐私政策适用于「时间戳记录器」（包名 com.timestamp.recorder，以下简称"本应用"）。我们深知个人信息的重要性，并致力于保护你的隐私。本政策用通俗语言说明本应用如何处理你的数据。

1. 我们不收集任何个人信息

本应用不收集、不传输、不存储任何个人身份信息、位置信息、通讯录、相册、设备标识（如 IMEI/OAID）等数据。应用内没有任何账号体系、没有云同步、没有行为统计。

2. 数据完全存储在本地

你创建的事件（如"喝水""吃药""打卡"）和每一次记录的时间戳，仅保存在你设备的应用私有存储中，不会上传到任何服务器。卸载应用会删除这些数据，请提前使用应用内"数据备份"功能导出。

3. 不申请任何权限

本应用为纯本地工具，不申请网络、存储、相机、位置等任何敏感权限。桌面卡片为系统服务卡片能力，仅用于在桌面展示你的事件信息，不涉及个人信息收集。

4. 无第三方 SDK

本应用不含任何广告、统计、推送等第三方 SDK，不存在数据共享、出售或跨境传输行为。

5. 你的数据控制权

  • 随时可删除单个事件、单条记录或全部数据；
  • 支持一键导出全部数据为 JSON 备份文件；
  • 卸载应用即彻底清除本地数据。

6. 未成年人保护

本应用不涉及任何用户注册与内容提交，对未成年人同样无任何信息收集行为。

7. 政策更新

如本政策发生变化，我们将在此页面更新并标注新的生效日期。

8. 联系我们

如有任何疑问，可通过 GitHub 仓库 github.com/baoru0908/timestamp-recorder 提交 Issue 与我们联系。
