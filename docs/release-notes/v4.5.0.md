# TimestampRecorder v4.5.0

> 一个**只动界面、不动数据**的版本。事件色板数值一个都没改，备份格式仍是 format 2，
> 老用户的事件颜色、圆点、时间线渐变色、图表柱色、导入导出**全部不受影响**，无需任何迁移。

本次是 v4.0「液态玻璃」重设计之后最大的一次界面打磨：把散落在代码里的玻璃参数收成设计 token、
修掉深色模式的可读性问题、把系统原生弹窗/菜单换成自绘玻璃组件、补齐无障碍与大屏适配。

---

## 🌫️ 玻璃：修掉「深色压不住内容」与「有时变实心黑」

- **弄清了两套着色空间**：AGSL 着色器走的是 **sRGB** 混合，代码里原先按「线性空间」给的
  深色 tint 实际等于 38% 中灰 —— 越加浓度越**亮**。现在统一以 sRGB 十六进制声明颜色
  （`glass_tint` / `glass_tint_solid`），由 `Glass.kt` 一处负责换算，观感可预期、可回归。
- **分开两档浓度**（`values-night/dimens.xml`）：
  - 主页胶囊岛 + 顶部玻璃栏 **38%** —— 「液体玻璃」设计语言本体，保留内容从玻璃下透出的透亮感；
  - 二级页顶栏 **72%** —— 条目会不定期的从标题下面穿过，这里可读性优先。
    （中途曾一律加到 72%，玻璃被涂成实心黑，已按上述分档回退。）
- **顶栏加了「确定的底」**：新增三档滚动遮罩 `bg_top_scrim`（实 → 半 → 全透），
  标题行在任何滚动位置都压得住从下面穿过的列表内容。
- **玻璃参数全部收进 token**：模糊半径 / 折射高度 / 着色浓度 / 上限值原先散落在 Kotlin 里
  （`14f * density`、`0.38f` 这类魔法数），现在统一放 `res/values/dimens.xml`，
  深色覆盖放 `res/values-night/dimens.xml`。顺带修正了一处实现偏差：
  模糊上限原写成裸 `50f`（实为 50px ≈ 13dp），现改为 `glass_blur_max = 50dp`。
- **Android 7 ~ 12L 的顶栏有底了**：液态玻璃只在 API 33+ 可用，低版本原先直接把玻璃藏掉，
  而顶栏自身背景是透明的 → 顶栏变成**完全没有背景**，滚动时列表内容与标题字叠在一起。
  现在低版本自动挂 `bg_top_fallback`（普通玻璃底色 + 下沿分隔线）。

## 📋 菜单/弹窗：全部换成自绘玻璃，不再用系统样式

- **新增统一组件 `GlassMenu`**（自绘玻璃卡片、独立窗口、圆角 20dp + 描边 + 玻璃面，
  行高 48dp、图标 22dp、文字 15sp，危险项用 `colorError` 并垫淡红圆底）：
  - 主页「⋮」→ 设置 / 统计 / 使用教程
  - 事件卡「⋮」**以及长按卡片** → 编辑 / 删除事件
  - 事件详情页「⋮」→ 编辑 / 导出 / 统计 / 时间线 / 清空 / 删除（批量管理独立成工具栏 ☑ 按钮）
  - 此前详情页用的是 `onCreateOptionsMenu`（系统溢出菜单：白底直角、系统字重、系统动效），
    与 App 的玻璃语言完全不是一套东西，现已移除。
- **开合动画做成时间反演**：展开 190ms `Decelerate`，收起 190ms `Accelerate`（= 前者的时间反演），
  同一 pivot（锚点那一角）、同一组起止值（scale 0.88 / alpha 0）。
  卡片底从「窗口背景」迁到根视图 —— 否则背景不参与动画，收起只剩字在缩、卡片会"啪"地消失。
- **三条关闭路径行为一致**：再次点击锚点 / 点空白处 / 返回键，都走同一套退场动画。
  - 修掉一个触摸穿透的坑：菜单窗口原先带 `FLAG_NOT_TOUCH_MODAL`，点「⋮」那一下会被投递两份
    （一份当作"点外部"开始收起，一份漏给下层按钮又把菜单展开回来），表现为**再点 ⋮ 没反应**。
    现在窗口自己吃掉窗口外的触摸，锚点与空白处完全等价。
  - 返回键此前收不到（菜单窗口不可获焦），会直接退出页面；现由 Activity 接管：第一下只收菜单。
- **确认类弹窗统一配色**：删除 / 清空 / 导入 / 指引等弹窗共用一个主题叠加
  （`glass_dialog` 面 + M3 圆角），不再是系统中性灰白。
- **取色器与 App 同一套明暗**：原先直接挂 `Theme.Material3.DayNight.*`，在本工程里夜间会被解析成
  **Light**（DayNight 靠 `values-night` 换父主题，这里没有覆盖）→ 出现"白色浮层 + 夜间浅色文字"、
  文字直接看不见。现改为继承 App 自己的 `Theme.Timestamp` 系列，浮层底、标题、控件与页面共用一份颜色。

## 🎨 选色板（事件颜色）

- **自定义入口挪到第一位**：色盘首格就是「＋」，一眼可见可选；标签文案同步改为「选择颜色（第一个「＋」可自定义）」。
- **色板 24 → 23 色**：去掉与「蓝灰」区分度最低、观感最浑的**浅蓝灰 `#78909C`**，23 色 + 1 格自定义
  正好凑成 4×6 的整行网格。⚠️ 只影响「以后能选哪些色」，已存在事件的 color 是存进数据里的整数，一个都没动。
- **自定义色的纹理跟着底色走**：色格描边按底色亮度切换深浅，浅色底不再"白点白框看不见"。
- **白字可读约束**：取色器面板纵向按「白字仍达 WCAG AA 4.5:1」的明度上限收口，
  每个点都是「能压白字」的颜色；确定时再兜一次。此前可以取到纯白 → 事件卡上的色点、药丸、
  文字全糊成一片（真机实测踩到）。
- **面板联动与指示器修复**：拖动色相条时方形面板重建位图（原先只 `invalidate`，等于把旧色相再画一遍
  → 「拖色条方板不变」）；色相条上的指示竖条同步实时更新；换色相后把明度夹回新上限内。
- **尺寸自适应**：SV 面板固定 260dp 在 320dp 窄屏/横屏会溢出被裁，改为按屏宽收敛。

## 🏠 首页事件卡

- **快捷记录钮对齐**：原先用 `minWidth` 控宽，但 `minWidth` 对 `LinearLayout` 是空操作 ——
  「开始」52dp、「＋ 52」65dp，宽度随文案变，左边的「⋮」和「共 N 段」整列跟着左右漂。
  现改为**固定宽度 64dp**；6dp 间距挂到图标上（区间事件隐藏图标时不留残距），文字真正居中。
- **「共 N 段」徽章**：给最小宽度 56dp + 文字居中，宽度一致、右缘落在同一条竖线；
  并按需求**与右侧「⋮」同一条中线**（改成卡片主轴的直接子元素 + 垂直居中）。
- **文案不再被硬裁**：事件副标题改 `match_parent + ellipsize`，长文案（如「进行中 · 已 01:23:45」）
  显示省略号而不是被裁掉。
- **时段事件秒表不再整行闪烁**：计时刷新改用 `payload` 局部刷新，并关掉该次 `notifyItemChanged`
  的默认淡入淡出动画 —— 逐帧实测：右侧徽章/⋮/药丸区域逐帧变化 **0.000%**，只有秒表数字在变。

## 🧾 详情页与设置页

- **批量管理不再破坏底部保护**：进入/退出原先用裸像素改列表底部留白（`140` / `24`，本机 3.75x 下
  仅 37dp / 6dp），退出时还把**导航栏 inset 一起冲掉** → 用过一次批量管理后，最后一条记录永久停在
  手势条下面、点不到「复制」。现在改为「页面只声明额外需要多少，绝对值由 `BaseActivity` 统一算」。
- **设置页「添加小组件」三颗按钮改纵向整宽排列**：原先三颗横排（各占 1/3），M3 按钮左右各 24dp 内边距，
  384dp 宽屏下每颗只剩约 48dp 放字 ——「自定义小组件」被截成「自定义小组」。
  现在每颗都有约 260dp 放字，文案完整、文字居中、三颗宽度一致。
- **权限按钮不再截断**：去掉 `maxLines="1"` 硬裁，收窄横向内边距、允许换行（`minHeight` 48dp 兜住触摸高度）。
- 详情页主按钮高度 / 无障碍等随全局规范一并整理。

## 👶 自定义小组件配置页

- 原先这一页是全 App 唯一「不像自己」的页面：系统原生 `Button`、**8 处硬编码中文**、
  硬编码 `#1E88E5`、没有页面同款渐变底、无标题无返回。
- 现统一为「MaterialToolbar + 玻璃卡片分组 + MaterialButton + 底部主按钮」的版式，
  与「设置 → 桌面小组件」同一套语言；文案全部迁入 `strings.xml`，颜色走 `?attr/colorPrimary`，
  背景预览包进圆角卡；「全选 / 清空」触摸高度从约 30dp 提到 48dp。

## ⚪ 白字 / 深色底的可读性策略

- 统一为「**默认白字**，只有底色过亮时才转近黑」：判定用 WCAG 相对亮度 **> 0.45**，
  只会翻掉纯白（白字 1:1）、明黄 `#FDD835`（1.40:1）、琥珀 `#F9A825`（1.97:1）这一档，
  其余颜色保持白字，全 App 一套白字方案。
  > ⚠️ **已于 2026-09-21 变更**：阈值上调为 **> 0.60**（解读 B：白字一致性优先），
  > 琥珀 `#F9A825` 由近黑改回白字（1.97:1），仅明黄仍转近黑。
  > **本条为 v4.5.0 发布时的历史记录，保留原样不回溯改写。**
- 覆盖：首页快捷记录药丸（文字 + 图标）、详情页主按钮（文字 + 图标）、
  单事件小组件三种形态、自定义小组件（纯色背景时）。
  > 补充（2026-09-21）：上述规则同时被 `ColorAdapter` 用作**色块选中描边环**的颜色，
  > 故阈值变更也会影响选色板的选中态观感。
- 事件色板数值未变，所以老用户的事件颜色观感**零变化**。

## ♿ 无障碍

- **图标按钮补齐 `contentDescription`**：工具栏返回键、开发者卡片、记录行勾选框（读出该条时间）、
  色板每个颜色（「颜色 红，已选中」）等。
- **两张自绘图表**给出**一句话摘要**（如「各事件记录数：最多的是喝水，共 52 条；合计 7 个事件」）
  —— Canvas 绘制对读屏软件是一片空白，此前完全读不到。
- **纯装饰元素**标为不参与无障碍焦点：色点、时间线竖线与节点、绑定卡色点、关于页大图标、小组件背景层。
- **选中态**：底部 Tab 与统计页区间按钮暴露 `isSelected`，TalkBack 会播报「已选中」。

## 📐 平板 / 折叠屏 / 横屏

- 新增 `values-sw600dp` 尺寸集与运行时内容居中：大屏下内容收成**居中的一列（上限 640dp）**，
  行宽不再被拉到 800dp+；底部胶囊岛从「横贯全屏的长条」恢复为**居中的真胶囊（上限 360dp）**。
- 实现方式是「一处助手 + 尺寸上限」，不为每个页面复制一套 `layout-sw600dp`，布局保持单一事实源。
- 手机（< 600dp）路径是**空操作**（`content_max_width = 0`），观感与 v4.4.0 逐像素一致。

## 📱 兼容性

- `minSdk 24` / `targetSdk 34` 不变；**依旧零权限、完全离线**。
- 数据与备份格式**完全没有改动**（format 2），v4.4.0 的备份可直接导入。
- 事件色板 24 色**数值未变**（仅"以后可选项"少了 1 个浅蓝灰），老用户无需任何操作。
- 签名指纹不变（`cca83079…f8f976ce`），可直接覆盖安装。
