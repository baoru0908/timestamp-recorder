## 🐞 修复

### 1. 关于页去掉「未实现的功能预告」

- **问题**：关于页简介末尾写着「…快速记下一笔当前时间。**支持备注与标签（规划中）。**」——
  备注与标签功能至今**并未实现**，在「关于」页（对外门面）预告一个不存在的功能，
  容易让新用户误以为已具备。
- **修复**：删除「支持备注与标签（规划中）」整句，只保留对**现有能力**的准确描述。

### 2. 统计页 KPI 标签口径改准

- **问题**：统计页顶部 KPI 标签写作「**记录总数**」，但该数字**只统计点事件** ——
  代码 `StatsActivity` 里按 `filter { !it.isInterval }` 计算，**不含**时间段事件里的记录。
  叫「记录总数」会让人以为它等于全部记录数，与实际口径不符。
- **修复**：标签改为「**瞬间记录数**」，与「只数点（瞬间）事件」的实际口径一致。
  取值逻辑、布局与测试基线**均未改动**（仅 `strings.xml` 一处文案）。

> 说明：此标签为纯静态文案（`activity_stats.xml` 直接引用 `@string/stats_total_records`），
> 改名**无需**任何 Kotlin 改动；已 grep 全仓确认无其它引用。

### 3. README 补充「创建快捷方式」权限归属说明

- **问题**：README 第 5 节桌面小组件一节写「先授予「创建快捷方式」权限」，
  容易被读成「App 申请了一个权限」，与「**完全离线、零权限**」的定位相互矛盾。
- **修复**：在该处补注 ——「**这个权限属于桌面（启动器）侧，App 本身不申请任何权限**」，
  说明这是桌面弹框所带的权限、并非 App 声明，消除歧义。
