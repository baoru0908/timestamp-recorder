# TimestampRecorder v4.3.0

## 🗑️ 移除：2×1 胶囊小组件

桌面小组件由四种精简为三种，移除「时间戳 · 胶囊」（2×1，事件色填充，左侧事件名 + 右侧「记录」）。

- **保留的三种**：全部事件（列表）、单事件（大按钮，1×1 ~ 4×4 可拉伸）、自定义（自选事件 + 标题 + 背景色）。
- **设置页入口改为三颗横排**：设置 → 桌面小组件 →「一键添加到桌面」，按钮现在是
  **全部事件 / 单事件 / 自定义小组件** 并排三颗，不再分两行。

### ⚠️ 已添加过胶囊组件的用户请注意

- 桌面上**已添加的胶囊组件本次升级后会失效**：系统找不到对应的组件类型，
  多数桌面会显示「无法加载小部件」，个别桌面会留一份不再刷旧的静态画面。
- **请长按桌面上残留的胶囊组件 → 拖到「移除 / 删除」把它删掉**，再按需要添加
  「单事件」或「自定义小组件」替代。
- 这一版**不会删除你的任何数据**：事件、记录、备份文件都原样保留，只是少了一种小组件外观。

## 📱 兼容性

- 无架构变化、无新增权限、无数据格式变化（备份 JSON 仍为 format 2），App 依旧完全离线、零权限。
- 覆盖安装即可升级；「全部事件 / 单事件 / 自定义」三种组件不受影响，继续正常使用。
