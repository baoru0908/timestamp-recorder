# TimestampRecorder v4.7.3

> 一个**只做「代码整洁性重构 + 死资源清理」、对外零可见变化**的修复版。
> 没有新功能、没有新交互、没有新依赖；**界面观感、交互与数据格式完全不变** ——
> 时长显示文字、CSV 表头 / 文件名**与上一版逐字一致**。

本版把散落在代码里的中文文案统一**外置到 `strings.xml`**（为后续多语言与统一维护打基础），
并清理了一批随功能下线而遗留的**零引用字符串**，同时给 3 个「预留 / 未接线」资源补了注释。

---

## 🔧 重构（对外零变化）

### 1. 硬编码文案外置到 `strings.xml`

- **取色器**：颜色编码输入框的 `hint` / `helperText` / 无障碍说明（`color_picker_hex_hint` / `_helper` / `_cd`）。
- **详情页**：行复制文案、Unix 秒标点拼接（`unix_copy_text` / `unix_start_label`）、
  时间段范围拼接（`interval_range_text`）、裸「进行中」（`interval_ongoing`）、
  批量管理提示（`interval_batch_unsupported`）。
- **时间线**：月份标题 `%d年%d月`（`timeline_month_header`，改为在 ViewHolder 用 `getString`）。
- **统计页**：时长 KPI 的分隔冒号（`stats_kpi_sep`）。
- **时长**（`TimeFormat.duration`）：`0分钟` / `{d}天{h}小时` / `{d}天` / `{h}小时{m}分` /
  `{h}小时` / `{m}分钟` / `不到1分钟` 共 7 条（`duration_*`）—— 函数新增 `Context` 参数，
  全部调用点同步更新。**文字一字未改**。
- **自定义小组件**：布局里写死的「我的小组件」「事件」「＋」改为 `@string/` 引用
  （`WidgetPrefs` 里重复写死的「我的小组件」也复用既有 `widget_default_title`）。

### 2. CSV 表头 / 文件名（用户交付物，文字逐字不变）

- 文件名前缀与两种表头抽入资源（`csv_filename_prefix` / `csv_header_interval` / `csv_header_point`）；
  **UTF-8 BOM 与换行仍保留在代码**里。**表头文字（含半角逗号、`(毫秒)` 半角括号）与上一版完全一致**，
  已导出 CSV 的对照习惯不受影响。

## 🧹 清理

### 3. 删除 8 个零引用死资源

- `fab_pos_start` / `fab_pos_center` / `fab_pos_end`（「加号位置」设置项残留，该设置 v4.0.0 已移除）
- `timeline_interval`（已被内联字面量取代的孤儿）
- `toast_event_deleted`、`tutorial_intro`、`timeline_title`、`cd_event_dot`
- 删除前已**全仓复扫确认零引用**，`assembleRelease` 编译通过。

### 4. 3 个「未接线 / 预留」边界资源保留并加注释

- `toast_undone`（D1「防误触」规划预留）、`timeline_open_detail`、`cd_widget_custom`
  在 `strings.xml` 中**保留并标注**预留原因，**不删**。

## 🔧 说明

- 改动集中在「文案外置」与「死资源清理」，**不涉及业务逻辑**；`TimeFormat.duration` 仅增加
  `Context` 参数，**取值逻辑完全不变**。
- 「分 / 分钟」的既有混用**按中文习惯保留、未统一**（强行统一会得到不自然的「45分」）。
- 改动文件见本次 commit：① 文案外置 + 死资源清理 · ② CSV · ③ 时长。

## 📱 兼容性

- `minSdk 24` / `targetSdk 34` 不变；**依旧零权限、完全离线**。
- **界面观感、交互、数据与备份格式完全不变**（format 2），v4.7.2 的备份可直接导入。
- 签名指纹不变（`cca83079…f8f976ce`），可直接覆盖安装。
