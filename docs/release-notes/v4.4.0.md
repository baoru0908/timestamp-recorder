# TimestampRecorder v4.4.0

## 📊 统计页重构

- **概念分治**：点事件（条）与时间段事件（段 / 时长）不再混算。顶部改为 **2×2 KPI**：
  **事件数 / 记录条数（点）/ 时间段数 / 总时长** —— 不再把「条」和「段」相加成一个误导性总数。
- **焦点视图闭环**：从某事件的详情页进入统计时，顶部出现「**当前：X · 返回全部**」，
  一眼看清正在看哪个事件，一键回到全部事件视图（此前只有数据过滤、没有对应界面）。
- **趋势可切天数**：近 N 天记录趋势支持 **7 / 14 / 30 天**切换（原先写死 14 天）。
- **时长汇总**改用统一字符串资源（段数 / 总时长 / 平均 / 最长一次），不再在代码里硬编码中文。

## ⏱️ 首页：时间段事件更好读

- **补上「次数」**：时间段事件此前完全不显示次数，现在事件名右侧显示「**共 N 段**」徽章。
- **秒表读秒**：进行中改为 `MM:SS` / `H:MM:SS` 的**秒级跳表**（原先只到分钟，
  「不到 1 分钟」会一直挂着不动）；跳动对齐整秒，数字不抖。
- **按钮语义更清晰**：时间段事件的快捷钮显示「**开始 / 结束**」（原为「开始 / ■」）。
- **性能**：秒表刷新只重绘「进行中」那一行，不再每秒整表重绑。

## 🧵 时间线修复

- **修复「删除后仍显示」**：删除改为**按记录值 / 时间段开始时刻**定位（不再依赖列表下标），
  彻底消除下标错位导致的「删错条 / 删不掉」；详情页长按删除同样改为按行对象删除。
- **统一刷新**：主页新增数据变更监听（防抖），任何写入（含桌面小组件、恢复备份）都会让
  时间线与事件页自动跟上最新数据。
- **修掉重复实例**：详情页「时间线」入口改为复用同一主页实例（`singleTop` + `CLEAR_TOP`），
  不再叠加多个主页实例（旧写法返回时可能看到陈旧列表）。
- **文案**：时间线的距今时间去掉小时与分钟之间的逗号 —— 「3 小时, 25 分钟前」→「3 小时 25 分钟前」。

## 📱 兼容性

- 无架构变化、无新增权限、无数据格式变化（备份 JSON 仍为 format 2），App 依旧完全离线、零权限。
- 覆盖安装即可升级；已有事件、记录与备份文件全部原样保留。
