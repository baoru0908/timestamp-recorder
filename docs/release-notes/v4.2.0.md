# TimestampRecorder v4.2.0

## ✨ 新功能：时间段记录（开始 + 结束）

以前每个事件只能「点一下记一个瞬间」。现在新建 / 编辑事件时可选**记录方式**：

- **点时刻**（默认，原有行为）：点一下记一个瞬间，适合吃药、打卡、喝水。
- **时间段**：点一下「开始」计时、再点一下「结束」，自动算出这段用了多久，适合睡觉、开会、专注、通勤。

### 怎么用

1. 新建事件时选「时间段」；已有事件也可在「⋮ → 编辑事件」里改类型。
2. 主页 / 详情页 / 桌面小组件上点该事件卡片：
   - 第一次点 → **开始**（按钮变红、显示已用时长并每秒跳动）；
   - 第二次点 → **结束**（弹出时长，如「已结束：2小时15分」）。
3. 「时间线」里区间显示为 `开始 – 结束（时长）`；进行中的显示 `进行中 · 已 …`。
4. 详情页列表按段列出（开始–结束–时长），点一行复制、长按删除；「撤销上一条」救回手滑。
5. 统计页对区间事件汇总：总时长 / 平均 / 最长一次；导出 CSV 含开始、结束、时长三列。

### 设计取舍（v1）

- **无后台服务**：不挂通知、不常驻。结束时间点一下才写盘；进行中时「已用多久」在打开 App 时按当前时间现算——
  关掉 App 不影响，下次打开照样看到从开始到现在的时长。
- **同时最多一段进行中**：对同一事件再点「开始」会自动把上一段按当时结束，再开新段，不会两条同时跑。
- **暂不支持手动补记**开始 / 结束时间（如事后补昨晚的睡觉时段），后续版本再考虑。
- 区间事件的「批量管理」暂不开放，长按单段即可删除。

## 📦 数据与兼容

- 事件新增 `type` 字段（0=点 / 1=区间），**旧数据无该字段一律按点事件处理**，升级后原有事件与记录原样保留。
- 备份 JSON 升级到 **format 2**：新增 `intervals` 段；**format 1 的旧备份仍可导入**（区间为空）。
- 无新增权限、依旧完全离线、零联网。
