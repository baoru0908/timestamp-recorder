# TimestampRecorder v4.1.1

## 🐞 修复

- **异色小组件串色**：桌面上同时放两个颜色不同的小组件时，点其中一个记录，另一个卡片的颜色也会被"带跑"。
  原因是两个实例共用同一份圆角背景资源、又用「背景 tint」来染色，部分桌面（如 MIUI / HyperOS）会把 tint
  写进共享的图形状态，后刷新的实例就覆盖了先前的。现改为「底层图层 + 颜色滤镜」染色：
  滤镜应用前每个实例会先复制自身的图形状态，实例之间互不影响，与「全部事件」小组件既有的做法保持一致。
- **旧机型崩溃隐患**：原实现用到的染色接口是 Android 12（API 31）才提供，而本应用最低支持 Android 7.0（API 24），
  在 Android 7~11 设备上构建小组件会直接抛错。改用更基础的接口后不再依赖它，静态检查里的 9 项 API 越界告警同时清零。
- **点击可能记录到别的事件**：小组件点击凭据的编号取自事件 ID 并被截断，且该系统判等并不包含附加数据。
  现改为「编号按实例区分 + 附带实例与事件标识」，多个实例之间不再串用点击凭据。

## 📱 兼容性

- 无架构变化、无新增权限，App 依旧完全离线、零权限。
- 四个小组件布局重构为「背景图层 + 内容层」结构，观感、圆角与内边距与 v4.1.0 一致。
- 桌面小组件添加方式不变；已添加的小组件**无需重新添加**，升级后自动按新逻辑渲染。
