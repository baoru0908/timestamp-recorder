# TimestampRecorder v4.1.2

## 🐞 修复

- **窄版小组件的事件名不显示**：2×1 这类窄尺寸的单事件小组件里，事件名会被
  「记录时间 + 加号图标」挤掉几乎全部空间——留给名字的只剩几个 dp，
  中文名连省略号都放不下，于是整块空白（拉丁字母名则勉强挤出「i…」，看起来像"有的显示有的不显示"）。
  现在让**事件名优先**：
  - 宽度不足时自动隐藏加号图标（整块本就可点击，图标只是提示；3×1 及以上尺寸仍保留）；
  - 适当收紧左右内边距，并为事件名保留最小宽度，超长名字照常以省略号收尾。

## 📱 兼容性

- 无架构变化、无新增权限，App 依旧完全离线、零权限。
- 已添加到桌面小组件**无需重新添加**，升级后自动按新布局渲染。
- 其他形态（1×1 / 2×2 及以上）与「全部事件」小组件不受影响。
