## 🐞 修复

### 1. 关于页「不依赖任何第三方库」表述失真

- **问题**：关于页许可说明写着「本应用代码均为原创、**不依赖任何第三方库**」，
  与事实不符 —— App 集成了 MIT 许可的液态玻璃组件（`com.qmdeve.liquidglass`），
  并使用 AndroidX / Material 等标准库；同页的字体说明本就已承认第三方。
- **修复**：改写为「界面自绘、无广告、数据仅存本机；代码为原创实现，仅采用
  AndroidX / Material 等标准库与 MIT 许可的液态玻璃组件」，保留原意、不再失真。

### 2. 空状态引导方位指错

- **问题**：事件列表空状态提示「点击**右下角** + 添加第一个事件」，但加号圆钮实际固定在
  底部栏**正中间**（与内置教程里「点底部正中间的圆形「＋」」自相矛盾）。
- **修复**：改为「点底部中间的圆形「＋」添加第一个事件」，并把加号统一为**全角「＋」**。

### 3. 术语与标点统一

- 详情页批量管理提示「**区间事件**暂不支持批量管理」→「**时间段事件**…」，与全 App 其余
  叫法（「时间段」）统一。
- 记录行的 Unix 秒文案由半角 `(Unix 秒: …)` / `开始 Unix: …` 统一为全角
  `（Unix 秒：…）` / `开始 Unix：…`，与 `unix_label` 的「Unix 秒：」一致。

### 4. 过期注释修正（8 处）

- 色板注释：`EventRepository.kt`「Material 风格 **24 色**」→ **23 色**（色板早已精简为 23 色）、
  详情页布局「19sp 大字在 **24 色**任意一色上…」→ **23 色**。
- 小组件编号：`WidgetCustomProvider.kt` 与 `res/xml/widget_custom_info.xml` 的
  「小组件**类型四**：自定义」→ **类型三**（与 AndroidManifest 的「类型三：自定义」一致）。
- 刷新范围：`TimestampWidgetProvider.kt`「刷新**两种类型**全部实例」→ **三种类型**；
  `strings.xml` 的小组件分组注释「（**两种类型**）」→「（**三种类型**）」。
- 事件卡片前景色注释：由「统一白色」更正为「**默认白色，仅底色极亮（相对亮度 > 0.60）
  时转近黑**」，与 v4.6.0 起生效的 `EventColors.onColor` 阈值一致。
- 设置页头注释：由「快捷按钮（+）位置左/中/右切换…」更正为当前实际内容
  （事件排序 / 小组件圆角 / 一键添加与权限引导 / 数据备份 / 关于与内置教程）；
  「使用教程：交给系统浏览器打开 README」→「打开 App 内置的离线教程页」。

### 5. 移除已废弃的「加号位置」设置残留

- 删除死资源 `fab_position_label` / `fab_position_hint`，以及设置页布局里
