# TimestampRecorder v4.1.3

## 🐞 修复

- **单事件 / 胶囊小组件「添加到桌面」后不出现**：拖到桌面、选好要绑定的事件后，
  配置页直接关闭、桌面却空着一个组件。根因是配置页结束时只回了 `RESULT_OK`，
  **没有把 `AppWidgetManager.EXTRA_APPWIDGET_ID` 放进结果 Intent**——launcher 认不到
  这次配置对应哪个 widgetId，于是按「无效」把组件丢弃。现在返回结果里带上了 widgetId，
  选完事件组件即正常落地。
- **「全部事件」小组件里所有圆点只剩一个颜色**：六个圆点在布局里共用同一份
  `bg_dot` shape，代码再逐个 `setColorFilter` 染事件色——资源 drawable 默认共享同一实例，
  后设的滤镜把前面的覆盖掉，最终所有圆点都渲染成最后一个事件的颜色。改为**按事件色
  预渲染独立圆点 Bitmap** 再设给每一行（带颜色缓存），各圆点互不串色。

## 📱 兼容性

- 无架构变化、无新增权限、无数据格式变化，App 依旧完全离线、零权限。
- 已添加到桌面的组件无需重新添加；圆点颜色在下次刷新（记录 / 回到前台）后自动正确。
- 单事件 / 胶囊组件需重新绑定事件的情况不变；本修复只解决「选完事件加不上」。
